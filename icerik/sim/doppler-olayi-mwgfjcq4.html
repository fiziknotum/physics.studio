$\text{Önde (yaklaşan): } f' = f_0\,\dfrac{v}{v - v_k}$
$\text{Arkada (uzaklaşan): } f' = f_0\,\dfrac{v}{v + v_k}$
$\text{Dalga boyu: } \lambda' = \lambda_0\left(1 \mp \dfrac{v_k}{v}\right)$
$\text{Mach sayısı: } M = \dfrac{v_k}{v}\,,\quad v = \lambda_0 f_0$
Ses altı ($v_k \lt v$): $\text{Yaklaşırken cepheler sıkışır: }\textbf{frekans artar}\text{ (ses incelir).}$
Ses altı ($v_k \lt v$): $\text{Uzaklaşırken cepheler seyrekleşir: }\textbf{frekans azalır}\text{ (ses kalınlaşır).}$
Ses duvarı ($v_k = v$): $\text{Önde cepheler üst üste biner, } f' \to \infty \text{ (basınç yığılması).}$
Ses üstü ($v_k \gt v$): $\text{Mach konisi oluşur: } \sin\theta = \dfrac{v}{v_k} = \dfrac{1}{M}\text{ (şok dalgası).}$
